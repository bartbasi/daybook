# Daybook

A free, open-source tracker for food, macros, micronutrients, body weight, resistance training and cardio. The whole point is speed of entry: type a whole meal on one screen, log a set in one tap, log your weight in under five seconds.

Daybook is free, with no ads, no accounts and no tracking. Your data stays on your phone. The only network call is an Open Food Facts lookup when you scan a barcode.

It is in early development (Phase 2 of [PHASES.md](PHASES.md)). The plan is in [BRIEF.md](BRIEF.md).

## Building

You need Flutter 3.47.7 (stable), JDK 17 and the Android SDK.

```bash
flutter pub get
flutter test
flutter run
```

Database code is generated by drift. After changing `lib/data/database.dart`:

```bash
dart run build_runner build
dart run drift_dev make-migrations   # after raising schemaVersion
```

The bundled USDA food database (`assets/food/usda.sqlite.gz`) is built from the USDA download files by:

```bash
python tools/build_food_db.py
```
