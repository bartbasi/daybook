Saved meals and aliases

Lighter wireframes. A saved meal has a name and any number of other names (aliases). Any of them, typed in Food entry, expands to the items. The two saved meals are the fixtures in docs/parser-grammar.md 11.1.

Frame width: 360 dp (phone) 344 dp (Z Fold 5 cover screen) 673 dp (Z Fold 5 unfolded)

The saved items are shown as added lines: each holds its food and amount, and tapping one opens the same sheet as Food entry to change or remove it. Items that are not touched never change.

The empty box below adds more items by typing, with the same parser and lines as Food entry. Typed items join the list when the saved meal is saved.

Other names: each must be unique; a name already used by another saved meal is refused with a plain message.

Saving a saved meal never changes meals already logged.
