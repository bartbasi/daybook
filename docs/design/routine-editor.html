Search box with focus. Muscle chips filter (one at a time). The library is the bundled wger list plus your own exercises. Before anything is typed, recent exercises are listed first.

Add puts the exercise at the end and keeps the picker open, so several can be added in a row; Back closes it.

Create opens a short form: name, primary and secondary muscles, equipment.

The same picker is used by "+ Add exercise" during a workout.
