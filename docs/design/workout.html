Daybook design / Workout logging

Workout logging

Sample: Push A on Thu, Nov 12 at 5:30 pm, prefilled from the last Push A on Thu, Nov 5. The workout screen keeps one exercise per card, sets as rows, and a large check button at the end of each row.

Frame width: 360 dp (phone) 344 dp (Z Fold 5 cover screen) 673 dp (Z Fold 5 unfolded)
Speed target: start yesterday's or last week's routine. Target: 1 tap from Workouts.
  1. Tap Start on the row (frame 1). The workout opens with every set prefilled (frame 2).
Taps: 1 from the Workouts tab. Pass. From Home it is 2 (the Workouts tab, then Start). Condition: a workout was logged on that day. "Start again" always lists yesterday's workout first and the workout from the same weekday last week second, when they exist, then other recent ones, each with the day named ("Yesterday", "Last Thursday"). A routine can also be started from its own row, 1 tap.
Speed target: log a set using prefilled numbers. Target: 1 tap.
  1. Tap the check button at the end of the set row (frame 2 to frame 3).
Taps: 1. Pass. The set is saved at once, marked Done, and the rest timer starts. Conditions: the exercise has been done before (the first time, weight and reps are empty and must be typed), and the set is on screen (the list scrolls to the next set by itself after each log). No permission prompt can appear in this path: the rest timer runs inside the app with no permission.
Decision for Bart: estimated 1-rep max formula. Chosen: Epley, weight x (1 + reps / 30). Alternative: Brzycki, weight x 36 / (37 - reps). They agree at 10 reps; Epley reads a little higher at low reps. Only sets of 1 to 12 reps count toward the estimate.
Decision for Bart: what counts as a personal record. Chosen: heaviest weight for the exercise, and best estimated 1-rep max. Rejected for v1: most reps at each weight, best set volume (more labels, little extra use).
Decision for Bart: weekly volume. Chosen: completed sets per muscle, counting each exercise's primary muscles only, Monday to Sunday. Alternative: weight x reps per muscle (tonnage). Sets are easier to compare across exercises and work for body-weight moves.
Decision for Bart: rest timer alerts. Chosen: the timer runs in the app with no permission and vibrates at the end while Daybook is open. A one-time row on the timer bar, "Alert me when rest ends", asks for notification permission only when the user taps it; after that, a notification "Rest done" also appears when Daybook is in the background. No permission prompt ever appears while logging a set. Rejected: asking for permission the first time the timer starts (puts a system prompt in the 1-tap set path); never alerting in the background.
Decision for Bart: calories for strength workouts. Chosen: one Compendium MET value for resistance training times body weight times workout time, shown at Finish and changeable. The value is 3.5 MET, code 02054 in the 2024 Compendium.

Start again: yesterday's workout first (Wed, Nov 11, Legs), then the one from the same weekday last week (Thu, Nov 5, Push A), then other recent ones (Mon, Nov 9, Pull A). Start copies that workout's exercises and number of sets.

A workout started empty, with no routine, is named in this list by its first exercises, for example "Squat, leg press, 2 more".

Routines: the user's templates, each with Start. "+ New routine" opens the routine editor.

Empty workout starts with no exercises; "+ Add exercise" opens the picker.

This week, sets by muscle is the weekly volume: Mon Nov 9 Pull A and Wed Nov 11 Legs so far. Bars have the number next to them.

While a workout is running, the Start buttons are replaced by one "Return to workout" button, so two workouts cannot run at once.

Every set shows last session's weight and reps for that exercise (here Thu, Nov 5). They are real values, not hints: tapping the check logs exactly what is shown.

The next set to do has a heavy outlined check button. Done sets have a filled "Done" button and bold numbers. Neither depends on color.

When the workout starts, every planned set is stored as a set row that is not yet completed. Tapping the check marks that row completed at once. So closing the app, or the phone dying, loses nothing. Leaving the screen keeps the workout running; Home and the Workouts tab show "Return to workout".

The exercise menu (...) holds: replace exercise, remove exercise, move up or down, exercise details.

Set 1 is Done. The rest timer starts by itself with the routine's rest time for this exercise (90 s), and shows what is next.

-15 s and +15 s change this rest only. Skip hides the timer. Logging the next set also ends it.

The timer needs no permission. "Alert me when rest ends" is shown once; only tapping it asks for notification permission, so no system prompt ever interrupts logging a set.

The timer bar sits at the bottom, above the gesture area, and does not cover the set rows; the list gets shorter instead.

Tap the weight or reps of any set. The sheet has -5 and +5 lb (-2.5 and +2.5 kg in metric), -1 and +1 reps, and either number can be typed.

Here set 3 goes from 175 x 7 to 180 x 8: +5 once, +1 once, Done. The row then shows the new numbers with a "Changed" label, and one tap on its check logs it.

Taps for this example: the number, +5, +1, Done, then the check: 5. One step on one value is 4.

Remove set deletes it from today only.

Finish ends the workout at once (no "are you sure"), and this summary is shown. Resume reopens it.

Volume: bench 175x8 + 175x8 + 180x8 = 4,240; overhead press 3 x 95x8 = 2,280; incline dumbbell press 3 x 50x10 = 1,500; triceps pushdown 3 x 50x12 = 1,800; lateral raise 3 x 20x12 = 720. Total 10,540 lb over 15 sets.

Calories are added to the day's budget at the add-back setting. Change opens a number box, and the value is kept as an override.

Planned sets that were never logged are deleted at Finish, so the history holds only work that was done. If there are any, the summary lists them first ("2 planned sets not logged, removed"); Resume brings them back.
