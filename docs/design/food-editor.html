Opened from the not found line "1 zorbo" in Food entry, so the name is filled in and the cursor is in it. The user types the numbers from the package. Saving returns to Food entry with the line matched.

Required: name, the amount the values are for, and calories. Everything else is optional and shows as "not listed" if empty, never as 0.

The amount can be per serving, per 100 g, or per 100 ml. A serving can have a weight so "g" and "oz" work in Food entry too.

A saved recipe opened again: its ingredients are added lines, each holding its food and amount; tapping one opens the same sheet as Food entry. The empty box adds more ingredients by typing. A new recipe starts with only the box, and works like Food entry.

Ingredient names and portions are real USDA foods and portions.

680 + 353 + 103 + 56 + 45 = 1,237 kcal for the whole pot (P 113, C 93, F 49). "Makes 4 servings": 1,237 / 4 = 309 kcal, P 28, C 23, F 12 a serving. Lines show kcal only here to keep the frame short.

Typing "1 serving turkey chili" in Food entry then matches it. So does "2 servings chili": a user's own food wins when the last word of its name was typed (docs/parser-grammar.md, 5.4 key 2 and example 74).
